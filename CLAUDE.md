# Working rules for Claude Code in this repo

1. **Plan first.** For every task, start by reading the relevant files and writing a plan: what you will change, which files, and how you will test it.
2. **Ask for approval.** End the plan with a clear question and stop. Do not create, edit or delete any file until I reply with explicit approval (e.g. "approved" or "go").
3. **Build only what was approved.** If you find that the plan needs to change while building, stop and ask again.
4. **Report back.** After building, list every file changed, show the test results, and flag anything uncertain.
5. **Never** commit, push or delete files unless I ask for it.

Data in this repo is simulated. Follow the definitions in `docs/metric_dictionary.md` and `docs/assumptions.md`.
